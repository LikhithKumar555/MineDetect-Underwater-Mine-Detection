# Sample data (synthetic)

`demo_sensor_readings_SYNTHETIC.csv` is **generated data, not a real sensor
recording**. It exists so this repo can be run end-to-end (feed it to
`ml/train_svm.py` or `run_demo_prediction.py`) without needing the physical
submarine or Arduino attached.

It was generated by `generate_sample.py` in this folder, with a fixed random
seed, using value ranges loosely modeled on what the firmware's scaling
logic produces (see `firmware/combined_sensor_streamer_MAIN.ino` and the
"How the 9 features are built" section of the root README) — a near-511
baseline when nothing trips a threshold, and large jumps when one does.

**Do not present this file as real recorded data.** The real datasets used
for training and the live demo are in `../data/`, and are themselves subject
to the caveats in the root README (duplicate rows, a partly-random 9th
feature, no feature scaling).
